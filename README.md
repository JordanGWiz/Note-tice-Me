# Note-tice-Me

## Overview

Note-tice-Me is a web app designed to help you manage your time by allowing you to effortlessly add, view, and delete notes. It offers a convenient way to keep track of reminders and important information wherever you go.

## Installation

To set up and run Noteworthy locally:

1. Clone this repository to your machine.
2. Run `npm install` to install all required packages.
3. Start the server using `node server.js`.
4. Open your browser and navigate to `http://localhost:3001` to use the app.

## Usage

- Start by clicking "Get Started" to begin creating notes.
- Fill in the title and text fields for your note, then click the "Save" icon to store it.
- To review an existing note, simply click on it from the list.
- You can delete any note by clicking the trash icon next to it.
